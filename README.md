# GroupeMax – Jeu de stratégie en Java

## Présentation

GroupeMax est un jeu de stratégie développé en Java dans le cadre de ma formation en informatique.

Le jeu se déroule sur un plateau de 10 × 10 cases. Deux joueurs s'affrontent avec des pièces noires et blanches en essayant de former des groupes pour obtenir des points.

## Fonctionnalités

- Interface graphique développée avec Java Swing.
- Mode deux joueurs.
- Mode joueur contre ordinateur.
- Intelligence artificielle avec choix de coups aléatoires.
- Vérification des coups autorisés.
- Calcul des scores.
- Sauvegarde et restauration d'une partie.

## Technologies utilisées

- Java
- Java Swing
- Programmation orientée objet
- Gestion des événements
- Collections Java (ArrayList)

## Organisation du projet

- `Main.java` : lancement du jeu.
- `FenetreJeu.java` : interface graphique.
- `Jeu.java` : gestion du déroulement d'une partie en console.
- `Plateau.java` : gestion du plateau et des règles.
- `Joueur.java` : gestion des joueurs.
- `IA.java` : choix des coups de l'ordinateur.

## Objectif du projet

Mettre en pratique mes connaissances en Java, notamment la programmation orientée objet, les interfaces graphiques et la gestion des données.
